# Administrador de Club Deportivo

## Proyecto Final (MVP) – Android Studio

La aplicación está orientada a la gestión administrativa de un **Club deportivo**, permitiendo el registro y control de socios y no socios, así como el manejo de cuotas y vencimientos.

---

## Objetivo

Desarrollar una aplicación Android que facilite la administración de un club deportivo, centralizando la información de socios, pagos y vencimientos de cuotas.

---

## Funcionalidades

La aplicación cuenta con las siguientes funcionalidades:

- **Registro de socios y no socios**
- **Cobro de cuotas**
  - Cuota **mensual** para socios
  - Cuota **diaria** para no socios
- **Entrega de carnet** (opcional)
- **Listado diario de socios**
  - Muestra los socios cuya cuota vence en la fecha actual

---

## Tecnologías usadas

- **Lenguaje:** Kotlin  
- **Entorno de desarrollo:** Android Studio  
- **Sistema de construcción:** Gradle  
- **Arquitectura:** Proyecto Android estándar
